## 1. What the bot is

ProGuard is an all-in-one Discord bot for server management. It provides:

- Moderation tools (bans, kicks, timeouts, warnings, auto-moderation)
- Server security alerts and logging
- Tickets, announcements, giveaways, and reaction roles
- Staff tools (LOA tracking, clock in/out, cases and mod logs)
- Fun and utility features (levels, economy, memes, trivia, weather, and more)

## 3. What information the bot stores

The bot stores the following, **only inside its own local data files** on the
machine or host it runs on:

- **Server settings** — which channels/roles are configured (log channel,
  welcome channel, autorole, etc.)
- **Moderation records** — warnings, numbered cases, blacklist entries, and
  the reason + moderator for each action
- **Staff records** — LOA (leave of absence) entries and clock-in totals
- **Member activity data** — XP/levels, economy coin balances, giveaway data
- **Logs** — command usage, moderation actions, member joins/leaves, and
  deleted/edited messages **only in servers where logging is enabled by the
  server's administrators**

The bot does **not**:
- Sell, rent, or share this data with anyone
- Run ads or track you for advertising
- Send your data anywhere except the Discord server it is serving

Data is stored in plain files on the host. The server owner controls it and can
delete it at any time by deleting the bot's data files or removing the bot.
